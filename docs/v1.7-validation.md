# WatchCat 1.7.0 只读系统与容器指标验证

验证日期：2026-08-23
目标设备：`nasw`
包：`community.lazycat.app.watchcat`
交付形态：单一 LPK

## 安全边界

- 不使用 `services` 拆分第二个 Collector。
- 不启用 `privileged`、host PID 或 host network。
- 不挂载整个 `/proc`、`/dev`、`/var/run` 或其他应用数据目录。
- LazyCat HAL 仅调用 `GetFanRpm`。
- Docker 客户端只实现容器列表和单次 Stats GET 请求。
- 不实现容器创建、启动、停止、删除、Exec、文件复制或任意 API 转发。

## 新增指标

- CPU 使用率与 5/15 分钟负载
- Swap 使用量
- 块设备累计 IO
- 逐接口网络 IO、错误和丢包
- 可见温度传感器
- LazyCat HAL 风扇转速
- 容器 CPU、内存、网络和块 IO
- 基于 `lzcapp.app-id` / `home-cloud.app-id` 的应用资源聚合

## 可信度规则

- 温度、风扇和容器 socket 没有实际返回数据时标记为 `unavailable`。
- 温度告警按稳定传感器类别评估；逐 CPU 核心和 NVMe 子传感器保留原始数据但不直接触发通知。
- 相同告警指纹和相同转换类型具有 10 分钟通知冷却，避免瞬时抖动形成通知风暴。
- 容器指标超过 2 分钟不进入应用实时聚合。
- SMART/Btrfs 没有安全数据源时继续保持 `unavailable`。
- 应用状态仍以官方 Package Manager API 为准，容器指标只是资源补充。
