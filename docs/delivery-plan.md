# 生产版交付计划

## P0：生产基础

- 仓库重构、配置管理、数据库迁移、结构化日志
- Hub/Collector 协议和版本协商
- CI、测试框架、可复现 LPK 构建

## P1：安全接入

- 一次性配对码
- 设备身份、mTLS、证书吊销和轮换
- Collector 能力探测及有界离线队列

## P2：指标与设备

- 系统、网络、文件系统、Btrfs、SMART/NVMe、LPK Runtime 采集
- 指标摄取、历史查询、降采样和保留策略
- 设备清单与设备详情接入真实 API

## P3：告警与巡检

- 告警规则、状态机、确认、静默、恢复和维护窗口
- LazyCat 系统通知
- 白名单巡检、原始证据、报告及导出

## P4：生产验收

- 安全、断网、故障、备份恢复、升级回滚测试
- 100 台设备压力测试
- 7 天稳定性测试
- 单一 WatchCat LPK、校验文件和运维文档
