# Screen Map · Penpot 第二版

| 第二版 Board | 生产入口 | 实现 |
|---|---|---|
| `01 · 统一应用框架` | 全局 | 240 px Sidebar、72 px Topbar、范围、新鲜度、搜索、通知、用户 |
| `02/03 · 设备群总览` | `#overview` | 日常运营与事件响应由真实状态自动切换 |
| `04/19 · 设备清单` | `#devices` | 保存视图、筛选、批量选择视觉、真实设备表 |
| `05/20 · 设备详情` | `#devices` 选择设备 | 六页签、身份、实时资源、风险、能力、原始证据 |
| `06/21 · 应用矩阵` | `#apps` | 应用 × 设备矩阵；内部横向滚动 |
| `07/17 · 存储风险` | `#storage` | 容量、磁盘、SMART/Btrfs 能力与风险证据 |
| `08/22 · 告警处置` | `#alerts` | 生命周期、确认、静默、自动恢复、服务端回读 |
| `09/10/23 · 巡检` | `#inspections` | 正式巡检任务、报告、历史与 SHA-256 证据 |
| `11/24 · 设备接入` | `#onboarding` | 独立接入向导与一次性配对码 |
| `25 · 设置中心` | `#settings` | 阈值、通知、能力、保留、备份、角色与审计边界 |
| `12 · 系统状态` | 所有数据页 | Loading / Empty / Error / Stale / Unknown |

## 响应式

- `≥1180 px`：双栏/三栏桌面布局。
- `760–1179 px`：核心内容降为单栏，宽表内部滚动。
- `<760 px`：68 px 紧凑 Sidebar；属于工程降级，不替代第二版移动端 Board。
